# 网站适配

已有站点入口在 `src/legacy/sites.js`，原有解析实现保留为本地模块，由 `src/parser.ts` 暴露类型明确的 catalog / chapter / validate 接口。后续可在这个接口下拆分平台适配器，而不用修改任务调度和存储。

先在工作台用 CSS 规则验证：目录选择器必须匹配链接；正文选择器只匹配章节文字；下一页 / 章选择器匹配实际链接；目录分页选择器独立设置。按 hostname 保存用户规则，用户规则优先于已有提示，最后使用通用结构识别。

解析输出需要包含目录标题和 URL、章节标题和文字、实际下一页 URL；章节标题必须与目录一致。同章分页总数和页码一致，跨章链接必须连接目录下一项。未知分页只有在同网站、同章标题下才能继续。

测试请覆盖：序章 / 番外、目录翻页、重复链接、章节分页、最后一章、广告清理、编码、订阅或验证提示。不要通过删掉校验来让失败样本显示成功。报告区分入口可访问、样本正文通过、目录完成和整本下载通过。

跨子域名仅允许已登记平台的同站子域名，并且仍需要浏览器域名授权。未知网站只允许同源。请求重定向会停止，请使用最终公开网址；不增加开放代理或任意跨站请求入口。
