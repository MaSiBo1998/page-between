## 复现

```sh
npm ci
npm run check
node tests/fixture-server.mjs
```

另开终端设置 `BROWSER_EXE` 为浏览器绝对路径，`BROWSER_LABEL` 为 `edge` 或 `chrome-stable`，运行 `npm run test:browser`。最新悬浮交互运行 `node tests/browser-overlay.mjs`；Chrome 使用以 `chrome` 开头的 label。

集成脚本使用临时浏览器配置文件、测试副本及本地服务器。产物位于已忽略的 `test-results/`，不包含在源码交付 ZIP 或 Git 跟踪中。不要对个人日常浏览器配置文件运行集成脚本。

## 验证边界

20 个平台的入口与部分真实章节样本证据来自先前站点调研，详见 [sites.md](sites.md)，不能视为当前扩展已完成所有平台整本下载。动态正文、登录、订阅、验证码和特殊字体仍可能阻止正文获取。随机请求时间不能保证网站不会限流。

首次网站授权、真实大型小说全流程、扩展商店审核、Firefox 和移动端浏览器未验证；首版以桌面 Chrome / Edge 为目标。
